Alternative routes through one step — GitHub Issues vs another door, npm vs Task.

```jsx
<TabbedPanel tabs={[
  { label: 'task', content: <CodeBlock code="task start" /> },
  { label: 'npm', content: <CodeBlock code="npm run start --prefix website" /> }
]} />
```

Tab labels are mono and lowercase — they name a tool, not a sentence. Active tab carries the 2px madder edge.
