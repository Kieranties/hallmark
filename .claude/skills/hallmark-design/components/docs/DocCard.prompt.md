A link card for a doc or section — use in grids of 2–3 on index pages.

```jsx
<DocCard title="Enable a repository" icon="power" href="/docs/enable"
  description="From an unenabled repository to one that runs the practice."
  meta={<Badge>5 steps</Badge>} />
```

Hover moves the hairline to madder and lifts the shadow one step. Never more than three per row.
