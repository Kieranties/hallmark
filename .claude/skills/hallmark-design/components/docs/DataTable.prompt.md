The docs table — declarations, carriers, commands, lifecycles.

```jsx
<DataTable columns={[{key:'path',label:'Path'},{key:'holds',label:'Holds'}]}
  rows={[{ path: <code>website/</code>, holds: 'The Docusaurus site' }]} />
```

Headers are mono, uppercase, tracked, on a sunk fill. Rows separate with hairlines only; no zebra striping.
Keep cell values short — a table is a lookup, not prose.
