The only icon primitive. Wraps a Lucide glyph and inherits `currentColor`, so colour comes from the surrounding text.

```jsx
<Icon name="check" size={16} />
<Icon name="arrow-right" size={18} label="Next" />
```

Sizes: 16 inline with text, 18 in UI chrome, 20–24 as a feature mark. Never emoji, never a hand-drawn SVG.
