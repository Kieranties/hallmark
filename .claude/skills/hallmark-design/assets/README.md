for this design system, at the user's request.

## The mark

A **maker's signature**: a cursive lowercase *h*, written in two strokes — the looped ascender and
the arch with its exit flourish — sitting on the rule a silversmith's mark is struck against. It carries the same claim as an assay punch — *this was checked, and someone
answers for it* — without the enclosing cartouche, which read as a warning sign.

Geometry is fixed: a 64×68 artboard, a 4.2-unit stroke with round terminals, and a 1.6-unit rule beneath. Do not redraw it, rotate it, add gradients to it, or place it
inside a container shape.

Clear space: one stem width (~4 units) on all sides. Minimum size: 22px for the mark, 130px wide
for the lockup — below that the ascender loop closes up.

## Iconography

No icon set exists upstream. This system standardises on **Lucide** (CDN) — 24×24, 1.5px stroke,
square caps — the closest match to the mark's flat geometric line. Flagged as a substitution; see
`readme.md` → ICONOGRAPHY.
