# UI kit — the Hallmark docs site

A recreation of `hallmark.kieranties.com` (source: `website/` in
[Kieranties/hallmark](https://github.com/Kieranties/hallmark)) rebuilt on this design system, so
you can see what the brand does to the Docusaurus classic theme without running the site.

| File | Surface |
| --- | --- |
| `index.html` | The interactive shell — routes between landing and docs, toggles light/dark |
| `Chrome.jsx` | Navbar (logo, Documentation link, search affordance, GitHub, theme toggle) and dark footer |
| `LandingPage.jsx` | `website/src/pages/index.md` — hero on the punch-grid field, scaffold warning, "Where to go" cards, status |
| `DocsPage.jsx` | The docs layout: 270px sidebar, 70ch article, 220px TOC, prev/next pager. Two articles, from `website/docs/index.md` and `docs/README.md` |

## What is real and what is stand-in

- **Copy is verbatim** from the repository's markdown. Nothing was rewritten.
- The published site's Mermaid flowchart is shown as a `FlowStrip` of boxes; the real site renders
  it through `@docusaurus/theme-mermaid`.
- Search is an affordance only — the upstream site has no search plugin configured.
- Syntax highlighting is omitted; Prism handles that in the real build.

## Porting this back to Docusaurus

Nothing here needs swizzling. Copy `tokens/*.css` into `website/src/css/` and import them from
`custom.css`, whose Infima overrides are already written in `tokens/docusaurus.css`. Components in
this kit map onto theme features that already exist: `Callout` → `:::` admonitions, `TabbedPanel` →
`<Tabs>`, `DocCard` → generated-index cards, `DocPager` → pagination, `SidebarNav` → the
autogenerated sidebar.
