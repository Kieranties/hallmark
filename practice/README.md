# The practice documents

**This file is not part of the practice.** It records where these documents came from, so
an actor reading them knows what it is holding. Everything else in this directory is the
practice; nothing here is.

## What these are

The nine documents beside this file are **verbatim copies** taken from the Obsidian vault at
`Z:\Obsidian\Stadion\Notes\Hallmark\` on 2026-08-17. Each is byte-identical to its source at
the time of copying.

They are here because the `work` and `verification` skills look for `practice/` in the
repository root **first**, and fall back to a local drive that only one machine can reach. An
actor that cannot reach these documents cannot hold a role — so while they lived only in
Obsidian, no actor outside that machine could act at all.

## Two things to know before relying on them

**Obsidian is still the editing home.** These are copies, and nothing keeps them in step with
the vault. A copy that has silently drifted from its source is worse than a missing one,
because it still answers when asked. Until that is resolved, treat the vault as authoritative
where the two disagree, and re-copy rather than editing here.

**Obsidian syntax does not resolve here.** `[[Wikilinks]]` between documents, section links
like `[[Hallmark - Glossary#Role terms|actor]]`, the `projects:` frontmatter, and the
`![[mentions.base]]` embed at the foot of several files all dangle outside Obsidian. They were
left exactly as written rather than rewritten, because rewriting the source would make these
no longer copies.
