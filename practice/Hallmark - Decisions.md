# Hallmark - Decisions

**Every decision, and the reasoning that produced it.** Not the deliverable — kept so that no decision is silently reversed and no argument is had twice.

**Two views of the same 186 rows.** The **index** below is one line each with its supersession marker: enough to see what is settled and what has moved. The **record** underneath carries the *why*. They are in one file deliberately — keeping them in two was a recurring source of drift.

> [!WARNING] The supersession column is load-bearing
> A blank marker means *nothing later changed this* — and that claim is only as good as the last sweep. **Read the record row before reopening or contradicting a decision.** Markers lead with the D-number so an attribution survives truncation.

## Editing this table

- **Insert new rows immediately after the last row**, never before the following heading. Obsidian's linter fragments the table otherwise.
- Rows are **append-only in numbering**. A superseded decision is *marked*, never deleted or renumbered.
- Write the **record** row first, then the **index** row. **Both carry the marker.**
