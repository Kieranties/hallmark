# Question

**A request for information.** It produces an answer, not a change — and how it resolves says
something about the system rather than about the asker.

| Resolution | What it tells you |
| --- | --- |
| The answer existed and was findable | **Retrieval is failing** — it should never have needed asking |
| The answer existed only in someone's head | **Write it down** — which raises a [chore](./chore.md) or a [capability](./capability.md) |
| The answer did not exist | Something is **undesigned**. That is a decision to take, not work to do |

**The rate of questions arriving is a signal about the system, not about the people asking.**
Answers routinely producing new work is the normal, healthy case.
