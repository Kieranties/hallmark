# Fix

**Correcting something previously completed.** It *attaches* to an existing
[capability](./capability.md) and never creates one.

- The capability holds, but not in every case
- It holds, but no longer meets a stated [standard](./standards.md) — too slow, too costly
- It stopped holding after a change elsewhere

**If you cannot name the capability it attaches to, it is not a fix.** Work correcting
something that was never completed is not a fix either — it is still part of completing it.
