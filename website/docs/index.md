# Documentation

Hallmark is a delivery practice: a set of declarations, states and criteria a repository adopts
so that claims about work are checked rather than asserted. It says what must be true for a piece
of work to have reached a given point, who may confirm it, and what has to be written down along
the way. It names no tool and no tracker — how a repository realises any of it is that
repository's own choice.

The practice is written in six sections. This page says what each one covers; the sections
themselves say what the practice is.

| Section | Covers |
| --- | --- |
| **[Foundations](./foundations/the-four-principles.md)** | The four principles everything traces to, how a practice differs from the application that adopts it, and the five things never conceded |
| **[Language](./language/how-hallmark-names-things.md)** | How Hallmark names things, the index of every word it reserves, and the words it has retired |
| **[The parties](./parties/the-structure.md)** | Who acts — the parties, the actors they supply, and the four roles an actor may hold |
| **[Items](./items/the-door.md)** | What travels: the door everything arrives at, the eight types, what a commitment is, and how work is called to attention |
| **[The loop](./loop/the-track.md)** | The track an item runs, state by state, and what each state asks before it is left |
| **[What an act requires](./acts/sufficiency.md)** | What an act must be able to reach, which standards it answers to, and what it must leave behind |

**If you are reading this to work an item**, [The loop](./loop/the-track.md) is the page to keep
open. **If you are an agent fetching a definition**,
[Reserved words](./language/reserved-words.md) is the index, and every entry names the one page
that owns the term.

:::note[What is not here yet]
Two sections of the practice are not written. **Claims and evidence** — what may be claimed and
what proves it — and **Applications**, the technology-specific material that instantiates the
practice on a real repository. Terms belonging to the first are named at the foot of
[Reserved words](./language/reserved-words.md) rather than left to look unreserved.
:::
