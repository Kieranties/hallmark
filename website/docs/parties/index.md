# The parties

**Two kinds of party, distinguished by their *object* — never by a verb.**

```
PERSONA  ──┐                        a party the running SYSTEM serves
           ├──►  ACTOR  ──►  ROLE
DISCIPLINE ┘                        a party that acts on the CHANGE
```

A party acts as itself, or delegates to an agent, in order to perform a
[role](./roles.md). Neither branch is optional: without
[disciplines](./disciplines.md) most of the track holds roles with no party above them;
without [personas](./personas.md) there is nothing to state a
[capability](../work/capability.md) *for*.

**The practice enumerates neither branch.** Which personas a system serves, and which
disciplines act on it, are declared by each
[application](../practice/practice-and-application.md). The practice supplies only the test
that sorts them — and examples.
