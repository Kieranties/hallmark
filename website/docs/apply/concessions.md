# Concessions

**To concede is to state that a [standard](../work/standards.md) has not been met, name who
accepted that, and proceed anyway.** The concession is that record — attributable to a named
[actor](../parties/actors.md), scoped to what it excuses, expiring, and counted.

**Nothing is absolute — the practice can always be departed from.** What it does not allow is
departing from it *silently*. A concession is how a compromise stops being invisible and
becomes a tracked liability with a name against it — and it is what keeps the process
traceable at precisely the points where the process was not followed.

**A concession is therefore not an exception to the practice — it is the practice working.**

## What a concession carries

| | |
| --- | --- |
| **Attributable** | To a named actor, with a human accountable through [delegation](../parties/accountability.md) |
| **Scoped** | To what it excuses. An unscoped concession is a standard quietly lowered |
| **Expiring** | It carries a point beyond which it no longer excuses anything |
| **Counted** | Open concessions are a query, not a report |

**A concession may be recorded at any point.** It is a record *on* the work of what could not
be met — never a decision, never a branch. It changes nothing about where the work goes; it
changes what is known about it, and who is answerable for that. See
[the states](../process/states.md).
